# Qwen–Luna Same-Corpus Evaluation Protocol v1

Status: protocol only. It authorizes no Luna call, credential, runtime adapter,
fallback or provider switch.

Freeze the Region Manager outcomes for the Qwen pilot first. A later,
separately authorized offline comparison may send the identical canonical
reference/evidence byte pairs to Luna using the same pair order, rubric,
locale, structured-result contract, output limit, tools-off posture and
reasoning setting. Provider labels must be hidden during usefulness scoring.

Record per provider only aggregate strict-schema success, agreement with the
frozen human decision, false-pass, false-fail, abstain/recapture, p50/p95
latency, actual input/output usage, billed cost per valid structured result and
cost per human-useful result. Record the observed Luna alias and timestamp
because an undated alias is not an immutable snapshot.

On 30 July 2026 the owner reported an approximately 80% Luna price reduction.
Treat that as a trigger to rerun the cost comparison, not as a hard-coded price
claim or an authorization to add a Luna runtime adapter. At evaluation time,
capture the then-current official unit prices and the provider-billed usage for
the same corpus; the receipt must calculate both the expected and actually
billed cost from that dated evidence.

Do not claim statistical accuracy from a 30–50 pair pilot. The existing human
outcome may have been influenced by Qwen and that limitation must accompany the
result. Any provider selection, fallback or production activation requires a
new owner decision and implementation PR.
