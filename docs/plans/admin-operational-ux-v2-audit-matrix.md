## Scope

This PR-1 audit covers the active Admin route graph frozen by Admin UI
Modernization V1:

- 31 active `/admin/*` routes.
- 16 admin navigation items.
- Explicit parked exceptions: `/admin/session` and `/admin/feed`, rechecked by
  PR-9 evidence.
- Runtime code remains unchanged by this document.

The audit uses repo evidence only: `admin-shell.tsx`, `admin-navigation.ts`,
the V1 inventory, the V1 closeout, active admin page files, AdminSurface guard
coverage, route parity guard coverage, and existing E2E spec names.

## Decision Rubric

Decision Latency:

- `low`: the primary decision is visible in the first viewport with no required
  navigation.
- `medium`: one filter, expansion, tab, or detail context is needed.
- `high`: multiple context switches, hidden dependencies, or unclear
  drill-downs are needed.

Evidence Confidence:

- `clear`: visible status, timestamp, reason, count breakdown, linked entity,
  audit trace, or disabled-action reason explains the state.
- `partial`: evidence exists but is split across panels, detail routes, or
  multiple linked records.
- `weak`: the current API/model does not expose enough visible evidence; do not
  invent it in UI.
