# HR Axis 06 Logo Assets

These raster assets are extracted from the selected concept 06 in the first logo exploration board. They are prototype assets, not a final vector logo package.

## Files

- `hr-axis-06-source-panel.png`: full selected concept panel reference.
- `hr-axis-06-horizontal.png`: horizontal mark + wordmark lockup.
- `hr-axis-06-mark.png`: circular mark crop.
- `hr-axis-06-mark-transparent.png`: transparent mark for UI placement.
- `hr-axis-06-wordmark.png`: wordmark crop.
- `hr-axis-06-chip.png`: small app/platform chip rebuilt from the centered mark.

## Usage

- Use `hr-axis-06-horizontal.png` for review pages and large brand previews.
- Use `hr-axis-06-chip.png` for compact platform seals in login prototypes.
- Use `hr-axis-06-mark-transparent.png` when the mark sits directly on a page background.
- If this concept becomes final, create a clean SVG/vector version before production rollout.
