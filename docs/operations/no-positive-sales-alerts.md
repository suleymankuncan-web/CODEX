# No-positive-sales alert operations

The API-side alert poll runs every 15 minutes after 06:00 Europe/Istanbul. It evaluates the previous business day only after the same daily source has successful sales, footfall, and GSM components. A store needs 15 consecutive successful sales days; a sales-expected primary assignment must be at least 15 days old. Positive sales at any store reset the period; returns do not.

The feature is disabled unless `NO_SALES_ALERTS_ENABLED=true`. Company email and egress settings belong in a separately reviewed operator configuration, not the synthetic base or company-data overlay. Supply `NO_SALES_SMTP_HOST`, `NO_SALES_SMTP_PORT` (default `587`), `NO_SALES_SMTP_FROM`, `NO_SALES_SMTP_USER_FILE`, and `NO_SALES_SMTP_PASSWORD_FILE` as mounted restrictive files. The approved SMTP route must preserve TLS verification end to end. Supply `NO_SALES_HR_RECIPIENTS_JSON` as a JSON object mapping company UUIDs to arrays of approved HR email addresses. No default HR address is inferred. Manager recipients come only from currently active direct store assignments with an active `REGION_MANAGER` role and account email; `region_id` is not a recipient source.

Each employee/assignment/no-sale period/recipient has one ledger record in `ops.no_positive_sales_alert_delivery`. SMTP preflight failures leave records pending for the next poll. A definite authentication or recipient rejection before SMTP message acceptance returns to `pending` for a safe retry. A failure with potentially accepted DATA, or a stale sending claim, is marked `uncertain` and must be reconciled by an operator before any resend. Never automatically retry an uncertain delivery. The email contains no automatic personnel status or incentive adjustment command.

The read-only `docs/operations/personnel-auto-roster-review.sql` reports provisional auto-created personnel with source import batch and sale/return evidence. Review each item with HR before changing any assignment; neither this query nor the alert feature deletes or deactivates personnel.
