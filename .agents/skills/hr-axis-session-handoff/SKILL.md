# HR Axis session handoff

Follow the repository AGENTS.md reading map; do not duplicate its policy or
start subagents from this skill. Read additional references only when the task
requires them; reuse already-read context until evidence or instructions change.

## Resume

Verify the actual workspace, branch, worktree status and relevant remote state.
Reconcile the newest user instruction with current-state and live evidence.
State the active goal, protected dirty files, unresolved gate and next safe step.
Do not select a branch or infer deployment readiness from a historical PR note.

## Record

- current-state.md: active decisions, evidence date, blockers and next action.
- discipline.md: durable execution rules; sokrates.md: decision/risk rules.
- Relevant docs shelf: detailed plans, receipts and historical evidence.

Keep the active handoff below 6,500 characters, with Now/Next/Park/Stop,
verification date and current external gates. Archive superseded narratives;
do not copy the archive back into a resume. Follow the task row in AGENTS.md.

Record exact references and distinguish verified facts from assumptions.
Never include secrets, private data, chat transcripts or complete successful
logs. Do not turn a handoff into unrelated code edits or claim missing live proof.

Check the diff, links and applicable documentation contracts. A cold reader
should identify the goal, protected work, evidence gaps and next action without
reconstructing the whole conversation.
