# Integration Test Scaffolding

This folder is reserved for integration tests covering:
- auth and scoped RBAC
- import batch creation and materialization
- snapshot run creation and snapshot generation
- checklist response and completion flows

Recommended first test files:
- `auth-scope.e2e-spec.ts`
- `import-batch.e2e-spec.ts`
- `snapshot-run.e2e-spec.ts`
- `checklist-flow.e2e-spec.ts`
